# To-Do List Application – Java

A simple console-based To-Do List application developed using Java for managing daily tasks.

## Features

- Add new tasks
- View all tasks
- Mark tasks as completed
- Delete tasks
- Exit the application

## Technologies Used

- Java
- Java Collections
